# 📝 WordPress Blog

> A modern WordPress installation with full-site editing capabilities, block patterns, and style variations.

## 🌟 Overview

This is a complete WordPress blog setup that leverages the latest WordPress features including the Full Site Editor (FSE), block-based themes, and extensive customization options. The project includes themes with multiple style variations, custom patterns, and comprehensive template parts.

## ✨ Key Features

- **Full Site Editing (FSE)** - Complete control over your site's appearance using the block editor
- **Style Variations** - 8+ style variations per theme for instant design changes
- **Block Patterns** - 50+ pre-designed patterns for banners, CTAs, events, and more
- **Responsive Design** - Mobile-first approach with fluid typography and spacing
- **Custom Fonts** - Includes DM Sans, IBM Plex Mono, Inter, Source Serif Pro, and more
- **Accessibility Ready** - WCAG compliant with proper ARIA labels and semantic HTML
- **RTL Language Support** - Full right-to-left language support
- **Custom Block Styles** - Enhanced block styling options for lists, quotes, and navigation

## 🚀 Quick Start

### Installation

1. **Clone or download the repository**
   ```bash
   git clone <repository-url> WP-blog
   cd WP-blog
   ```

2. **Set up your database**
   - Create a MySQL database for WordPress
   - Note your database credentials

3. **Configure WordPress**
   ```bash
   cp wordpress/wp-config-sample.php wordpress/wp-config.php
   ```
   
   Edit `wp-config.php` with your database details:
   ```php
   define('DB_NAME', 'your_database_name');
   define('DB_USER', 'your_database_user');
   define('DB_PASSWORD', 'your_database_password');
   define('DB_HOST', 'localhost');
   ```

4. **Run the installation**
   - Navigate to `http://your-domain.com/wordpress/wp-admin/install.php`
   - Follow the 5-minute installation wizard
   - Set your site title, admin username, and password

5. **Activate a theme**
   - Go to Appearance → Themes
   - Choose from Twenty Twenty-Three, Twenty Twenty-Four, or Twenty Twenty-Five
   - Click "Activate"

## 🎯 Usage Examples

### Creating a Custom Page with Patterns

1. **Create a new page**
   - Go to Pages → Add New
   - Click the "+" button to add blocks

2. **Insert a pattern**
   - Click "Patterns" tab
   - Browse categories: Banner, Call-to-Action, Contact, Events
   - Click a pattern to insert it

3. **Customize the content**
   - Edit text, images, and colors directly
   - Use the block toolbar for styling options

### Switching Style Variations

```
1. Go to Appearance → Editor
2. Click "Styles" in the top-right
3. Browse available style variations
4. Click to preview and activate
```

### Building Custom Templates

The themes use `theme.json` for configuration:

```json
{
  "version": 3,
  "settings": {
    "color": {
      "palette": [
        {
          "color": "#FFFFFF",
          "name": "Base",
          "slug": "base"
        }
      ]
    },
    "typography": {
      "fontSizes": [
        {
          "size": "1rem",
          "slug": "medium"
        }
      ]
    }
  }
}
```

## 🔧 Development

### Twenty Twenty-Five Development

The theme includes build tools for CSS optimization:

```bash
cd wordpress/wp-content/themes/twentytwentyfive

# Install dependencies
npm install

# Build minified CSS
npm run build

# Watch for changes
npm run watch
```

### Custom Block Styles

Register custom block styles in `functions.php`:

```php
register_block_style(
    'core/list',
    array(
        'name'         => 'checkmark-list',
        'label'        => __( 'Checkmark', 'twentytwentyfive' ),
        'inline_style' => '
            ul.is-style-checkmark-list {
                list-style-type: "\2713";
            }
        ',
    )
);
```

### Custom Pattern Categories

```php
register_block_pattern_category(
    'custom_category',
    array(
        'label'       => __( 'Custom Category', 'textdomain' ),
        'description' => __( 'Custom patterns', 'textdomain' ),
    )
);
```

## 🔌 Extending WordPress

### Plugin Development

WordPress has a robust plugin API. Create custom functionality without modifying core:

```php
<?php
/**
 * Plugin Name: My Custom Plugin
 * Description: Custom functionality
 * Version: 1.0
 */

add_action('init', 'my_custom_function');

function my_custom_function() {
    // Your code here
}
```

### Theme Customization

Use child themes to customize without losing updates:

```css
/*
Theme Name: Twenty Twenty-Five Child
Template: twentytwentyfive
*/

/* Your custom styles */
```
